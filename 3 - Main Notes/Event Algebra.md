# Event Algebra $\digamma$
It is a set that is a _collection_ of subsets of $\ohm$ 
	It is not a subset of $\ohm$ 

$\digamma \subseteq \mathcal{P} (\ohm)$ 

Here $\mathcal{P}(\ohm)$ denotes the _Power set_ of $\ohm$
	Power set is the set of all subsets of $\ohm$ 

## $\sigma$ Algebra
$\digamma$ is called $\sigma$ algebra if,
1. $\ohm \in \digamma$ 
2. if $A \in \digamma$, then $\bar A \in \digamma$ 
3. if $A_1, A_2... \in \digamma$, then $\bigcup_{i=1} ^{\infty} A_i \in \digamma$
	And when $\digamma$ is $\sigma$ algebra, it contains the full space.
	It is closed under taking complements.
	It is closed under countable unions.
